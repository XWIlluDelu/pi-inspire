# DocDoki panel

Run from the project root:

```bash
python3 .agents/tools/docdoki-panel.py .
```

Run without opening a browser:

```bash
python3 .agents/tools/docdoki-panel.py . --no-open
```

The script is a symlink to the DocDoki skill’s panel; this project does not own a copy.
