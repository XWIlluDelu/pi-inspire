# Trace prototype

A static, executable draft that explores the Trace direction against insπre's
three-region workbench. It is not production code and it is not a target
implementation.

Open `index.html` directly in a browser. It has no build step, dependencies, or
network requests.

## Contents

- `index.html` — draft markup.
- `styles.css` — draft visual system.
- `app.js` — local interaction wiring.
- `screenshots/` — light, dark, search, settings, and mobile captures.

## Use

The prototype makes several directions inspectable: square geometry, a grid
outside reading surfaces, the split between machine metadata and prose, and
squared tool/activity cards.

Do not copy its layout wholesale. Its composer treatment, workspace explorer,
divider density, top-bar controls, and empty-space distribution require a new
solution. Apply the direct feedback in `../README.md` before treating any part
of this draft as a candidate for implementation.
